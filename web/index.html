Pressure and temperature settings
Pressure shown = (sensor + correction), reduced to sea level when an altitude is set (standard atmosphere: p × (1 − h/44330.77)−5.2559; this is how an altimeter setting is defined, so the two compare directly). The BMP180's absolute error is up to −4/+2 hPa, so check against a nearby airport's current altimeter setting (it is already reduced to sea level, so the airport's own elevation does not matter; only this station's does). Repeat on a few days and average, because METARs are hourly and rounded to 0.01 inHg (0.34 hPa). Defaults: 285.9 m (938 ft) and no correction (Nov 6 23:34: KARB 30.03 inHg ⇒ 982.93 hPa here; the sensor read 982.93). Saved in this browser.

Waiting for receiver…

Rain: each tip is timed by the sensor and sent immediately; totals follow your browser's local midnight. If several tips arrive in one packet after radio loss, they are all credited at the time of the latest one.

“Instantaneous” means the latest completed full-revolution measurement, not an average of equal half-turns. Updates are radio-limited to about once per second. Idle heartbeat: 60 s. Gaps are not zero wind. Maintenance windows (shaded) are recorded but left out of graphs, averages and rain totals; manage them with the button above or maint.py. Sensor faults (red shading; fault.py) do the same for one sensor only, e.g. a disconnected anemometer wire that reads as calm. History retained for 7 days from server startup onward; only transmitted measurements are available. Times are estimated from reception time minus sensor-reported measurement age.
